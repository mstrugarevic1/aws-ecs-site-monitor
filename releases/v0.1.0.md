# v0.1.0

Initial portfolio release of `aws-ecs-internal-service-monitor`.

Included:

- FastAPI monitor API
- in-memory repository and local queue abstractions
- scheduler and worker services
- Dockerfile and Docker Compose
- Terraform infrastructure files
- guarded GitHub Actions workflows
- local validation and documentation

Not included:

- AWS deployment
- remote Terraform state
- GitHub OIDC trust in AWS
- HTTPS termination with ACM
